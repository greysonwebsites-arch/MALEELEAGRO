MALEELE AGRO-VET DEALERS WEBSITE

Files:
- index.html
- styles.css
- script.js
- assets/maleele-logo.png

HOW TO USE:
1. Upload all files to your GitHub repository.
2. Keep the "assets" folder and logo filename unchanged.
3. Enable GitHub Pages from Settings > Pages.
4. The website is responsive for desktop and mobile.

CUSTOMISE:
- Edit contact details in index.html.
- Replace/add product photos in the assets folder.
- Update social media links when available.

Brand direction:
Green + orange + black + white, matching the supplied Maleele Agro-Vet Dealers logo.
